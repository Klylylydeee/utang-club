`SETTLEMENT_RULES.md` - `ARCHITECTURE.md` - `DATA_MODEL.md`

Then inspect `PLAN.md` and implement Milestones 1 and 2 first.

The application is named **Utang Club**. Build the UI using the

across participants. - Preserve transaction history. - Add tests before
proceeding to UI-heavy milestones.

unless a genuine product decision is required. Make reasonable

commands to run the project, - environment variables required, -
